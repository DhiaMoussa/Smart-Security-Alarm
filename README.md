# Smart-Security-Alarm
Conception d'un système d'alarme intelligent à base de microcontrôleur, de capteurs de présence et d'une caméra. Détection automatique d'une présence humaine, déclenchement de la capture d'image et transmission d'alertes à distance. Projet associant électronique embarquée, automatisation, intégration de capteurs et communication sans fil.
