
# Smart Security Alarm System – GSM/SMS

## Présentation du projet

Conception d'un système d'alarme intelligent capable
de détecter une présence humaine, de capturer une
image et d'envoyer automatiquement une alerte.

Ce projet associe des capteurs, un microcontrôleur,
une caméra et un système de communication sans fil.

## Objectifs

- Détecter une présence humaine.
- Déclencher automatiquement une capture d'image.
- Transmettre une notification à distance.
- Automatiser les fonctions de surveillance.

## Réalisations techniques

- Intégration d'un capteur de présence.
- Programmation du microcontrôleur.
- Interfaçage d'une caméra.
- Déclenchement automatique de la capture d'image.
- Mise en œuvre de la transmission d'alertes.
- Coordination des différents composants électroniques.

## Technologies utilisées

- Microcontrôleurs
- Capteurs de présence
- Caméra
- Module GSM/SMS
- Communication sans fil
- Systèmes embarqués

## Compétences développées

- Électronique embarquée

- Automatisation

## Applications

- Surveillance électronique
- Sécurité automatisée
- Systèmes connectés
